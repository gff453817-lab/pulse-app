# نبض: موقع فيديوهات (Node.js + SQLite)

## التشغيل
    npm install
    JWT_SECRET="غيّر-هذه-لنص-طويل-عشوائي" npm start
ثم افتح http://localhost:3000

## الملفات
- server.js: واجهة API (تسجيل، دخول، رفع فيديو، إعجاب، تعليقات، متابعة)
- public/index.html: الواجهة
- data.db: قاعدة البيانات تُنشأ تلقائيًا (لا ترفعها إلى GitHub)
- uploads/: الفيديوهات المرفوعة

## قبل النشر للعامة
- شغّله خلف HTTPS (Nginx أو Caddy) واضبط JWT_SECRET دائمًا.
- خذ نسخة احتياطية من data.db ومجلد uploads.
- أضف حدًّا لمعدل الطلبات (express-rate-limit) وإشراقًا على المحتوى (حذف/إبلاغ).
- للفيديوهات الكثيرة استخدم تخزينًا سحابيًا (S3) بدل المجلد المحلي.
